## 2. Laporan Rincian Modifikasi Seluruh File

### 1. `koneksi_modifikasi.php` (Modifikasi dari `koneksi.php`)
- **Penerapan Karakter Charset UTF-8 (`utf8mb4`):**  
  Menambahkan fungsi `mysqli_set_charset($koneksi, "utf8mb4")` agar koneksi database mendukung seluruh jenis karakter khusus, simbol, tanda baca, serta teks bahasa asing tanpa terjadi kerusakan encoding (*character corruption*).
- **Notifikasi Koneksi Kondisional:**  
  Pada file asli, perintah `echo` status koneksi selalu tercetak setiap kali file di-`include` di halaman lain (seperti `index.php` atau `create.php`) sehingga mengotori tampilan UI web. Pada file modifikasi, pesan status sukses koneksi hanya akan muncul jika file `koneksi_modifikasi.php` dibuka/diuji secara langsung di browser, dan otomatis tersembunyi saat dipanggil melalui perintah `include`.

### 2. `index_modifikasi.php` (Modifikasi dari `index.php`)
- **Fitur Pencarian Data Mahasiswa (*Search Filter*):**  
  Menambahkan formulir pencarian dengan metode GET yang memungkinkan pengguna mencari data mahasiswa berdasarkan Nama maupun NIM dengan klausa SQL `LIKE`. Menyediakan tombol "Cari" dan tombol "Reset" serta menampilkan informasi total data mahasiswa yang ditemukan.
- **Penambahan Kolom Nomor Urut (No) dan *Empty State*:**  
  Menambahkan kolom penomoran otomatis (No. 1, 2, 3, ...) pada tabel agar baris data tersusun rapi. Jika data belum ada atau pencarian tidak cocok, tabel menampilkan baris pemberitahuan khusus yang informatif (*Empty State*).
- **Integrasi Aksi:**  
  Menghubungkan seluruh navigasi aksi ke file modifikasi (`create_modifikasi.php`, `edit_modifikasi.php`, dan `delete_modifikasi.php`) serta menambahkan dialog konfirmasi hapus data yang menyebutkan nama mahasiswa secara dinamis.

### 3. `create_modifikasi.php` (Modifikasi dari `create.php`)
- **Penggunaan Dropdown (`<select>`) untuk Program Studi:**  
  Input field "Prodi" yang sebelumnya berupa teks bebas diubah menjadi elemen dropdown pilihan (`<select>`) guna menyeragamkan data dan mencegah kesalahan ketik (*typo*) saat penginputan nama program studi.
- **Pembatasan Rentang IPK dan Tombol Navigasi Batal:**  
  Input IPK diberikan atribut `min="0"` dan `max="4.00"` beserta `step="0.01"` dan placeholder. Menambahkan tombol "Batal" berdampingan dengan tombol "Simpan" agar pengguna dapat membatalkan proses penambahan data dan kembali ke `index_modifikasi.php`.

### 4. `store_modifikasi.php` (Modifikasi dari `store.php`)
- **Sanitasi Input dan Validasi Kelengkapan:**  
  Menerapkan fungsi `mysqli_real_escape_string()` dan `trim()` pada seluruh nilai `$_POST` untuk mencegah celah keamanan SQL Injection dan menghilangkan spasi kosong. Menambahkan validasi kelengkapan bidang data serta batas nilai IPK (0.00 - 4.00) dari sisi server.
- **Pengecekan Duplikasi NIM (*Primary Key Validation*):**  
  Melakukan query pengecekan ke database sebelum menjalankan perintah `INSERT`. Jika NIM sudah terdaftar, sistem memunculkan peringatan bahwa NIM sudah ada dan membatalkan proses simpan guna menghindari error *duplicate entry*.
- **Pesan Konfirmasi yang Informatif:**  
  Notifikasi alert JavaScript menampilkan identitas spesifik mahasiswa (Nama dan NIM) yang berhasil disimpan sebelum diarahkan kembali ke `index_modifikasi.php`.

### 5. `edit_modifikasi.php` (Modifikasi dari `edit.php`)
- **Penguncian NIM (*Readonly Attribute*):**  
  Input field NIM dikunci menggunakan atribut `readonly` dengan tampilan visual abu-abu. Karena NIM bertindak sebagai *Primary Key* pada klausa `WHERE` proses update, perubahan NIM dicegah demi menjaga integritas data.
- **Dropdown Program Studi Otomatis Terpilih (*Selected Option*):**  
  Mengubah isian Program Studi menjadi dropdown (`<select>`) yang nilainya otomatis menyesuaikan (*selected*) dengan data yang tersimpan sebelumnya di database.
- **Validasi Keberadaan Data dan Tombol Batal:**  
  Jika parameter NIM tidak valid atau data mahasiswa tidak ditemukan di database, pengguna langsung dialihkan kembali ke `index_modifikasi.php` disertai pesan peringatan. Disediakan tombol "Batal" untuk kembali ke halaman utama.

### 6. `update_modifikasi.php` (Modifikasi dari `update.php`)
- **Validasi Metode Request dan Sanitasi Data:**  
  Menambahkan verifikasi metode pengiriman form (`$_SERVER["REQUEST_METHOD"] == "POST"`) untuk mencegah akses langsung ke file skrip tanpa submit form. Melakukan pembersihan data input dengan `mysqli_real_escape_string()` guna mencegah ancaman SQL Injection, memvalidasi kelengkapan form, serta memeriksa rentang IPK.
- **Verifikasi Data Sebelum Update & Pesan Hasil Update:**  
  Memastikan data mahasiswa yang akan diperbarui memang benar-benar ada di database sebelum query `UPDATE` dieksekusi. Notifikasi alert keberhasilan menampilkan Nama dan NIM mahasiswa yang telah diperbarui.

### 7. `delete_modifikasi.php` (Modifikasi dari `delete.php`)
- **Validasi Parameter URL dan Sanitasi Input:**  
  Menambahkan validasi keberadaan parameter NIM menggunakan `isset()` dan `empty()`. Jika file diakses langsung tanpa parameter, sistem memberikan alert peringatan dan mengembalikan pengguna ke `index_modifikasi.php`. Nilai NIM diamankan dengan `mysqli_real_escape_string()`.
- **Pengecekan Eksistensi Data dan Pesan Konfirmasi Spesifik:**  
  Menjalankan query `SELECT nama` terlebih dahulu untuk memastikan data mahasiswa ada di database dan mengambil nama mahasiswa tersebut. Pesan alert setelah penghapusan menampilkan identitas lengkap: *"Data mahasiswa: [Nama] ([NIM]) berhasil dihapus"*.

## 3. Lima Bagian Kode Paling Penting

### 1. Pengecekan Duplikasi NIM / Primary Key (`store_modifikasi.php`)

```php
$cek_nim = mysqli_query($koneksi, "SELECT nim FROM mahasiswa WHERE nim = '$nim'");
if (mysqli_num_rows($cek_nim) > 0) {
    echo "<script>
            alert('Peringatan: Mahasiswa dengan NIM $nim sudah terdaftar!');
            window.history.back();
          </script>";
    exit;
}
```
* **Penjelasan Singkat:**  
  Kode ini memvalidasi keunikan NIM sebelum query `INSERT` dijalankan. Hal ini sangat penting untuk mencegah terjadinya error *Duplicate Entry* dari database akibat pelanggaran integritas *Primary Key* ketika pengguna mendaftarkan NIM yang sama.

---

### 2. Sanitasi Input untuk Pencegahan SQL Injection (`store_modifikasi.php` & `update_modifikasi.php`)

```php
$nim  = mysqli_real_escape_string($koneksi, trim($_POST['nim'] ?? ''));
$nama = mysqli_real_escape_string($koneksi, trim($_POST['nama'] ?? ''));
```
* **Penjelasan Singkat:**  
  Fungsi `mysqli_real_escape_string()` menyaring karakter berbahaya seperti tanda petik, sedangkan `trim()` menghapus spasi di awal dan akhir input. Bagian ini krusial untuk menutup celah keamanan *SQL Injection* agar perintah berbahaya tidak dapat disusupkan ke dalam database.

---

### 3. Penguncian NIM dengan Atribut `readonly` (`edit_modifikasi.php`)

```html
<label for="nim">NIM (Primary Key - Tidak Dapat Diubah):</label>
<input type="text" id="nim" name="nim" value="<?= htmlspecialchars($data['nim']) ?>" readonly 
       class="bg-gray-100 cursor-not-allowed text-gray-600 ...">
```
* **Penjelasan Singkat:**  
  Kode ini menampilkan nilai NIM pada form edit tetapi menguncinya agar tidak bisa diedit oleh pengguna. Bagian ini penting karena NIM berperan sebagai *Primary Key* sekaligus acuan kondisi (`WHERE nim='$nim'`) saat update data, sehingga perubahan NIM dapat merusak integritas data.

---

### 4. Validasi Parameter URL Sebelum Eksekusi (`delete_modifikasi.php`)

```php
if (!isset($_GET['nim']) || empty(trim($_GET['nim']))) {
    echo "<script>
            alert('NIM tidak ditemukan atau tidak valid!');
            window.location.href = 'index_modifikasi.php';
          </script>";
    exit;
}
```
* **Penjelasan Singkat:**  
  Kode ini memeriksa apakah parameter NIM benar-benar dikirimkan melalui URL sebelum proses penghapusan dijalankan. Ini penting untuk mencegah munculnya *PHP Warning (Undefined array key)* serta menghindari eksekusi query kosong jika file diakses langsung lewat browser.

---

### 5. Logika Pencarian Data Dinamis dengan Operator `LIKE` (`index_modifikasi.php`)

```php
$cari = isset($_GET['cari']) ? mysqli_real_escape_string($koneksi, trim($_GET['cari'])) : '';
if (!empty($cari)) {
    $query = mysqli_query($koneksi, "SELECT * FROM mahasiswa WHERE nim LIKE '%$cari%' OR nama LIKE '%$cari%' ORDER BY nim ASC");
} else {
    $query = mysqli_query($koneksi, "SELECT * FROM mahasiswa ORDER BY nim ASC");
}
```
* **Penjelasan Singkat:**  
  Kode ini menyesuaikan query SQL secara dinamis berdasarkan input pengguna untuk mencari kecocokan pola teks pada kolom NIM atau Nama. Bagian ini penting untuk memudahkan pengguna menemukan data mahasiswa tertentu secara cepat saat volume data bertambah banyak.

##  Error, Penyebab, dan Langkah Perbaikan

### Pesan Error yang Pernah Muncul
```text
Fatal error: Uncaught mysqli_sql_exception: Duplicate entry '4524210091' for key 'PRIMARY' 
in C:\xampp\htdocs\pertemuan1\pertemuan6\store.php on line 13
```

### Penyebab Error
Error ini terjadi saat pengguna mencoba menambahkan data mahasiswa baru melalui form `create.php`, namun mengisikan NIM yang sudah pernah tersimpan sebelumnya di tabel `mahasiswa`. 

Karena kolom `nim` berstatus sebagai **Primary Key** pada skema basis data MySQL, nilainya harus bersifat unik (*unique*). Pada file `store.php` bawaan, query `INSERT INTO` langsung dieksekusi tanpa validasi pengecekan terlebih dahulu, sehingga database MySQL secara otomatis menolak data dan melempar eksepsi error fatal yang menghentikan jalannya program.

### Langkah Perbaikan
Pada file `store_modifikasi.php`, ditambahkan mekanisme validasi awal (pengecekan keunikan NIM) sebelum perintah `INSERT INTO` dijalankan:

1. **Menambahkan Query Pengecekan Eksistensi NIM:**
   ```php
   $cek_nim = mysqli_query($koneksi, "SELECT nim FROM mahasiswa WHERE nim = '$nim'");
   ```
2. **Memeriksa Jumlah Baris Hasil Query (`mysqli_num_rows`):**
   Jika ditemukan data dengan NIM yang sama (`mysqli_num_rows($cek_nim) > 0`), hentikan proses penyimpanan dengan `exit;` dan tampilkan notifikasi alert yang ramah bagi pengguna:
   ```php
   if (mysqli_num_rows($cek_nim) > 0) {
       echo "<script>
               alert('Peringatan: Mahasiswa dengan NIM $nim sudah terdaftar!');
               window.history.back();
             </script>";
       exit;
   }
   ```
3. **Hasil Setelah Perbaikan:**  
   Program tidak lagi mengalami crash/fatal error. Pengguna diarahkan kembali ke form sebelumnya (`window.history.back()`) dengan pesan penjelasan yang jelas sehingga pengguna dapat mengganti NIM yang belum terdaftar.
